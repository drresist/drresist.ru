# DrResist.ru

A small static starting point for the DrResist personal blog.

## Preview

Run a local web server from this directory:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Hosting

The public page is served from CloudCode by Caddy. This repository is the local source for the site; it is separate from the retired `wbtsre_blog` project.
